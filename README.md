# roplang

Низкоуровневый эзотерический язык, в котором инструкция и аргумент выводятся из SHA-256 строки. Текст программы не исполняется напрямую — каждая строка подбирается так, чтобы её хеш давал нужный опкод и аргумент (Proof-of-Work).

Коротко: это интерпретатор + ассемблер/«майнер» для языка, где op = sha256(line)[0] % 32, arg = u64_be(sha256(line)[1..9]).

## Возможности
- Виртуальная машина (VM) со стеком, памятью и вызовами.
- Ассемблер (.ropasm -> .rop), который «майнит» строки для нужных мнемоник и аргументов.
- Утилиты: запуск, дизассемблирование, майнинг одной строки, отладочный вывод SHA-256.
- Примеры в каталоге examples/.

## Быстрый старт (локальная сборка)
Требуется Rust (Rust 2021 / cargo).

Сборка релизной версии:
```
cargo build --release
# либо для быстрой отладки
cargo build
```

Запуск из cargo (в каталоге проекта):
```
# исполнить программу (.rop)
cargo run -- run examples/countdown.rop

# собрать .rop из .ropasm (Proof-of-Work)
cargo run -- asm examples/countdown.ropasm         # по умолчанию out = examples/countdown.rop
cargo run -- asm examples/countdown.ropasm -o out.rop

# дизассемблировать .rop (покажет op/arg и исходную строку)
cargo run -- dis examples/countdown.rop

# намайнить одну строку для мнемоники (пример: push 42)
cargo run -- mine push 42

# отладочный хеш
cargo run -- hash "текст для хеша"
```

Или использовать собранный бинарник:
```
./target/release/roplang run examples/countdown.rop
```

## Формат исходников и ассемблера
- Исходники на мнемониках имеют расширение .ropasm (в репозитории — examples/*.ropasm).
- Метки оканчиваются на `:`, комментарии начинаются с `;`.
- Ассемблер подбирает (майнит) текстовую строку для каждой инструкции так, чтобы sha256(line) давал нужный op и arg.
- Мнемоники: nop, push, pop, dup, swap, add, sub, mul, div, mod, shl, shr, and, or, xor, not, eq, ne, lt, gt, le, ge, jmp, jz, jnz, load, store, putc, putn, getc, call, ret.

Краткая спецификация компиляции (из SPEC.md):
- op  = sha256(line)[0] % 32
- arg = u64_be(sha256(line)[1..9])

## Структура кода
- src/main.rs — CLI и точки входа: run / asm / dis / mine / hash.
- src/vm.rs — реализация виртуальной машины (стек, память, инструкции).
- src/isa.rs — таблица опкодов и функция компиляции строки -> (op, arg).
- src/asm.rs — парсер мнемоник и «майнинг» строк (ассемблер).
- src/miner.rs — код майнинга (поиск строки с нужным хешом).
- src/sha256.rs — реализация SHA-256 (встроенная).

## Внутренние ограничения и поведение
- Стек поднимает ошибку при underflow (VM возвращает Err с сообщением).
- Память — фиксированный массив размером 1024 (индексация аргументом % 1024).
- push хранит значение arg % 65536.
- div/mod при делении на 0 возвращают 0.
- ret на пустом стекe вызвает завершение выполнения (halt).
